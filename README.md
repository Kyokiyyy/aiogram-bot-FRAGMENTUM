# FRAGMENTUM SHOP BOT

Telegram-бот для магазина одежды ручной работы **FRAGMENTUM**. Клиент листает каталог прямо в чате, сохраняет понравившиеся вещи в избранное и переходит к заказу у менеджера.

Написан на Python и [aiogram 3](https://docs.aiogram.dev/), избранное хранится в SQLite.

## Возможности

- **Главное меню** с логотипом, приветствием и кнопками навигации
- **Каталог по категориям**: худи, лонгсливы и футболки, джинсы и штаны, шорты, аксессуары
- **Карточки товаров**: фото, код, название, цена, описание, материал и срок пошива
- **Листание** товаров кнопками ◀ ▶ без лишних сообщений: бот меняет фото, текст и кнопки в одном сообщении
- **Избранное**: товар добавляется и убирается одной кнопкой (🤍 ↔ ❤️), список хранится в базе данных и не пропадает после перезапуска бота
- **Раздел «Избранное»** с отдельным листанием и удалением товаров
- **Кнопки «Заказать» и «Связь с менеджером»** ведут в чат с менеджером магазина

## Стек

- Python 3.10+
- [aiogram 3](https://docs.aiogram.dev/) для работы с Telegram Bot API
- SQLite (встроенный модуль `sqlite3`) для избранного
- python-dotenv для хранения токена

## Структура проекта

```
.
├── main.py              # точка входа: запуск бота
├── database.py          # работа с SQLite (избранное)
├── handlers/
│   ├── routes.py        # клавиатуры и обработчики кнопок
│   └── products.py      # категории и товары
├── photos/              # фото товаров
├── logo.png             # картинка главного меню
├── CATALOG.png          # картинка экрана каталога
└── .env                 # токен бота (в репозиторий не попадает)
```

## Запуск

1. Клонируй репозиторий и перейди в папку проекта.

2. Создай и активируй виртуальное окружение:

   ```powershell
   python -m venv .venv
   .venv\Scripts\Activate.ps1
   ```

3. Установи зависимости:

   ```bash
   pip install aiogram python-dotenv
   ```

4. Создай бота у [@BotFather](https://t.me/BotFather) и получи токен.

5. Создай в корне проекта файл `.env`:

   ```
   BOT_TOKEN=твой_токен
   ```

6. Запусти:

   ```bash
   python main.py
   ```

При старте бот сам создаёт файл базы `wishlist.db`.

## Как добавить товар

Товары лежат в `handlers/products.py`. Каждый товар это словарь внутри списка нужной категории:

```python
{
    "code": "FRG_6",
    "name": "OVERLOAD",
    "price": 7800,
    "description": "Кропнутое зип худи широкого силуэта.\n-большой капюшон\n-шнурок 160см",
    "materials": "футер 3-х нитка петля,\n330гр/м²\nхлопок 95% полиэстер 5%",
    "days": "12-15",
    "photo": "FRG_6.jpg",   # файл в папке photos
}
```

Фото кладётся в папку `photos`, имя файла должно совпадать со значением `photo`.
